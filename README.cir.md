# Знањограф

Дијагностички граф знања из математике за основну школу у Србији (1–8. разред): теме, везе претходних услова, банка проверених задатака и дијагностика која од изабране теме одлази уназад до највероватнијег места где је знање пукло.

> **Статус: у изради.** Скуп података и сајт још нису објављени. Дизајн је описан у [спецификацији](docs/superpowers/specs/2026-11-26-znanjograf-design.md).
