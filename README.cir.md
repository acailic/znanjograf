# Знањограф

Дијагностички граф знања из математике за основну школу у Србији (1–8. разред): теме, везе које кажу шта треба знати пре чега, банка задатака и дијагностика која од изабране теме одлази уназад док не нађе највероватније место где је знање пукло.

Сајт: <https://acailic.github.io/znanjograf/>, на латиници и на ћирилици. Исти текст на ћирилици: [README на ћирилици](README.cir.md).

> **Статус: рана верзија, садржај се уписује.** Алат, мотор дијагностике и сајт су направљени и проверени тестовима. Садржај се уписује разред по разред; табела испод показује шта је уписано, а свака страница сајта носи исту напомену док год неки разред нема теме с задацима. Садржај пишу AI модели и док га наставник не прегледа, треба га читати као нацрт.

## Како ради

1. **Мапа знања** показује теме и везе међу њима. Чврста веза значи „ово треба да знаш пре онога“; мека веза значи „ово помаже“.
2. **Дијагностика** креће од теме или од целог разреда. За сваку тему прво пита теже питање, а ако га дете промаши, лакше. Тема коју дете не реши ни уз лакше питање сматра се рупом; тада дијагностика иде уназад по чврстим везама и пита шта је пре ње, док не дође до најдубље теме коју дете не зна. Шта дете очито зна, не пита се поново.
3. **Резултат** је траг, а не оцена: где је знање највероватније пукло, које задатке је дете промашило и којим редоследом поправљати, од најнижег разреда навише.

Детаљно, с рачунатим примером: [Дијагностика: како ради](docs/dijagnostika.md).

## Шта је у репозиторијуму

- `data/` — сав садржај у обичном JSON-у: наставни програм по разредима, теме, везе, задаци, правила провере.
- `zg/` — алат који чита `data/`, проверава га, гради сајт и одржава евиденцију прегледа. Само стандардна библиотека Pythona.
- `site/` — сајт без фрејмворка: обичан HTML, CSS и ES модули, с KaTeX-ом за формуле; JavaScript се не пакује ни преводи.
- `docs/` — документација за наставнике, ауторе садржаја и програмере.
- `tests/` — тестови алата (Python) и мотора дијагностике (`node`).

## Како се покреће

Потребни су Python 3.12 или новији и `node` 22 (само за тестове мотора); ништа се не инсталира.

```sh
python3 -m zg build            # gradi sajt u _site/, u oba pisma
python3 -m zg serve            # služi ga na http://127.0.0.1:8765/ i gradi nanovo pri svakoj izmeni
python3 -m zg all              # sve provere: sadržaj, odgovore, notaciju, tabelu i ažurnost izgradnje

python3 -m unittest discover -s tests -q     # testovi alata
node --test "tests/node/**/*.test.js"         # testovi motora dijagnostike
```

## Шта Знањограф није

- **Није званичан** ни повезан са Министарством просвете. Ако се садржај не слаже с актом, важи акт.
- **Није оцена.** Резултат дијагностике је траг за разговор с дететом; не замењује наставников увид.
- **Није калибрисан на стварној деци.** Нико није мерио како деца одговарају на ове задатке.

Остало, без уљепшавања, стоји у [Познатим ограничењима](docs/poznata-ogranicenja.md).
