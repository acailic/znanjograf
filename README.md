# Znanjograf

Dijagnostički graf znanja iz matematike za osnovnu školu u Srbiji (1–8. razred): teme, veze prethodnih uslova, banka proverenih zadataka i dijagnostika koja od izabrane teme odlazi unazad do najverovatnijeg mesta gde je znanje puklo.

> **Status: u izradi.** Skup podataka i sajt još nisu objavljeni. Dizajn je opisan u [specifikaciji](docs/superpowers/specs/2026-11-26-znanjograf-design.md).
